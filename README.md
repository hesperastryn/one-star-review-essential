A deadpan one-star review of an everyday essential, written for make.fun's
"One-Star Review of Something Essential" bounty.

## The review

> Sleep: I gave it eight hours and woke up more tired than when I went in. Would not recommend the service.

## How it works

`main.py` (standard library only) writes the review, one line and under
160 characters, to `/output/entry.txt`.
